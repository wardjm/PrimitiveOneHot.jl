> [!NOTE]
> **This is a maintained fork of [chengchingwen/PrimitiveOneHot.jl](https://github.com/chengchingwen/PrimitiveOneHot.jl).** The upstream package is no longer
> actively updated, so I'm keeping this fork working with current Julia and current versions of its
> dependencies (GPUArrays 12, KernelAbstractions 0.10 and CUDA 6). The fork keeps the original package name and UUID but is not
> registered in General, so install it by URL:
>
> ```julia
> using Pkg
> Pkg.add(url = "https://github.com/wardjm/PrimitiveOneHot.jl")
> ```
>
> Issues and pull requests are welcome on this fork.
